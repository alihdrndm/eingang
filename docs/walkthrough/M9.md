# M9 — Packaging and the public demo

## What was built

- **Deployment** to three managed services, following `docs/DEPLOY.md` step by step:
  - Railway (EU West) runs three services from the repository: `api` (gunicorn, one worker with four threads), `worker` (the Temporal worker with SaxonC) and `temporal` (the official image in `start-dev` mode, its SQLite file on a volume).
  - Supabase (Frankfurt) provides PostgreSQL through the session pooler and a private S3 bucket for documents.
  - Vercel serves the static frontend and rewrites `/api/*` to the Railway API, so the browser sees one origin and the session cookie stays first-party.
- **Checks on the live site:** `/healthz` and `/readyz` (database and Temporal) return 200; a sandbox opens with the twelve samples; an uploaded XRechnung file went from upload to "needs review" in 3.6 s, through the worker, Temporal, storage and validation.
- **Docs:** README links the demo; `docs/COSTS.md` has the measured deploy cost ($0.02 on the first day) next to the always-on estimate ($5.61 per month); the CHANGELOG, CONTRIBUTING and SECURITY files are complete.

## Key decisions

1. **The deploy guide was tested by deploying, and corrected where reality differed.** Railway's builder rejects BuildKit cache mounts, so the Dockerfiles install without them; Railway replaces the image's entry point, so the Temporal start command needs `temporal` in front; region and networking settings only appear after a first deploy. `docs/DEPLOY.md` now matches what worked, and each deviation from the plan is in `docs/DECISIONS.md`.
2. **The proxy hop count was measured, not guessed.** Django's rate limits read the client IP from `X-Forwarded-For`, counting `TRUSTED_PROXY_HOPS` proxies from the right. With parallel requests and a spoofed header, 2 hops throttle correctly on the Railway domain and ignore the spoofed value. Through Vercel no value works, because Vercel's chain of addresses differs between requests. This is recorded as a known gap rather than hidden: the demo has the LLM switched off, so the gap cannot cost money. It does leave sign-in without a per-IP limit and lets one client use up the global sandbox cap, which `SECURITY.md` now says.
3. **Configuration lives in the dashboard, not in `railway.*.json`.** Railway has deprecated config as code. `docs/DEPLOY.md` lists every setting per service instead (Dockerfile path, pre-deploy command, health check, variables), and shared variables hold the secrets once for both backend services.

## How the parts connect

The Vue app calls relative `/api/v1/...` URLs, exactly as in development, where Vite's proxy does what Vercel's rewrite does in production. The API's pre-deploy step migrates, seeds the rules and creates the Temporal schedules before a new version takes traffic, so the API never serves requests against an older schema.

## Running costs

At the measured idle use, all three Railway services cost about $5.61 per month, above the $4.50 stop rule. The default is to pause them between demos (`docs/DEPLOY.md`, "Pausing the demo").
